# 江汉区期中模拟卷 · 错题教学工具包

依据《江汉区期中模拟卷 1》试卷图片的批改痕迹整理。工作区未提供 PDF，内容来自卷面照片识别。

## 文件

| 文件 | 说明 |
|------|------|
| `tutor.html` | **主工具**：六大薄弱点 · 学习 / 精讲 / 测试 / 反馈 |
| `index.html` | 轻量错题本与扩展练习 |
| `错题知识点总结.md` | 错题知识点文字总结 |
| `教学大纲.md` | 教学模块顺序与目标 |

## 使用

浏览器打开：

```bash
cd exam-review
python3 -m http.server 8765 --bind 127.0.0.1
```

- 教学训练营：http://127.0.0.1:8765/tutor.html  
- 错题本练习：http://127.0.0.1:8765/index.html  

进度保存在浏览器 `localStorage`，可在工具内一键清空。
